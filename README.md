# Portofino Restaurant & Café — Alexandria

الموقع الإلكتروني الرسمي التفاعلي لمطعم وكافيه بورتوفينو (الإسكندرية: فرع كامب شيزار وفرع لوران).

## مميزات الموقع
- **٣ مطابخ في مكان واحد:**
  - بورتوفينو (إيطالي ومتوسطي، بيتزا، باستا، مشويات، قهوة، حلويات).
  - سوفيا سوشي (١٢٢ صنف سوشي مع قائمة مستقلة لفرع لوران وتنبيه الضريبة).
  - مطبخ تحية (طواجن شرقية، فتة، محاشي، وأكلات إسكندرانية).
- **نظام الطلب والحجز المباشر عبر واتساب:**
  - سلة تفاعلية ذكية تراعي مركزية التوصيل من فرع لوران.
  - نموذج حجز الطاولات والمناسبات.
- **عروض اليوم الحية:** تبويب تلقائي بين عروض الفطار (٩٥ ج) وعروض الغداء الكومبو.
- **متوافق ١٠٠٪ مع الموبايل والتابلت والشاشات الكبيرة:** تصميم سلس سريع الاستجابة (RTL عربي أساسي + إنجليزي).

## كيفية التشغيل محلياً
يمكن فتح ملف `index.html` مباشرة في أي متصفح، أو تشغيل السيرفر المحلي:
```bash
node serve.mjs
```
ثم فتح المتصفح على: `http://localhost:5500/`
